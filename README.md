# vini.games

Vincent's game website.

## What is in here

- `index.html`: the website (welcome question, tour, search, game list, game page)
- `games/island-of-the-aquaris/index.html`: the game "Island of the Aquaris"

## Add a new game

1. Put the game in its own folder: `games/<game-name>/index.html`
2. Open `index.html` and find the list called `GAMES`
3. Copy one block between `{ }` and change name, text, tags and links

Every change saved here appears on vini.games after about a minute.
